# Concurrency patterns

Core concurrency patterns implementation

1. Blocking queue
2. Producer Consumer
3. Worker pool
4. Semaphore
5. Counter
6. Fan In/Out
7. Custom future
8. Structured concurrency
9. Rate limiter
10. Custom Read/Write lock

## Build and run
```
mvn clean install

java -jar target/ConcurrencyPatterns-1.0-SNAPSHOT.jar <command>
```
Use help command to see all available commands
